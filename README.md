# Telegram Bot + Admin Panel (x-ui)

یک ربات تلگرام فروش/ارائه سرویس با پنل مدیریت وب، متصل به پنل **3x-ui**. مناسب برای ارائه کانفیگ رایگان یا فروش اشتراک، با عضویت اجباری کانال، دانلودر، تبدیل فایل و پشتیبانی تیکت.

> این پروژه یک قالب (template) است: هیچ داده، توکن، آدرس سرور یا اطلاعات شخصی داخل آن نیست. همه‌چیز از `.env` و پنل مدیریت خودتان تنظیم می‌شود.

## امکانات

- **چند ربات تلگرام** روی یک نصب: هر ربات کاربران، امتیازها، کانال‌های عضویت اجباری و منوی مستقل خودش را دارد و از پنل افزوده/ویرایش می‌شود
- **پنل مدیریت وب** (React + Vite): داشبورد، کاربران، تیکت‌ها، پیام همگانی، فروشگاه، متن‌ها، منو و تنظیمات
- **کانفیگ رایگان / فروش** از پنل 3x-ui با محدودیت روزانه/هفتگی/ماهانه
- **پروکسی MTProto** برای تلگرام
- **عضویت اجباری در کانال‌ها** با بررسی خودکار عضویت
- **رفرال و امتیاز** با چک‌این روزانه
- **دانلودر** یوتیوب/اینستاگرام بر پایه `yt-dlp` با پشتیبانی پروکسی **SOCKS/HTTP** یا **کانفیگ V2Ray** (vless / vmess / trojan / ss / JSON) و **تست اتصال** از پنل
- **تبدیل فایل**: ویس ↔ MP3، Word → PDF (LibreOffice)، ویدیو → MP3 (ffmpeg)
- **منوی پویا**: دو ستونه، ترتیب، رنگ و متن دکمه‌ها از پنل
- **متن‌های ربات** کاملاً قابل ویرایش از پنل (`/texts`)
- **بکاپ و بازگردانی** دیتابیس از پنل (`/backup`) با بکاپ ایمنی خودکار قبل از بازگردانی
- **مدیریت حساب پنل**: تغییر نام کاربری و رمز عبور (`/account`)
- **آمار کانفیگ‌ها** (`/configs`): تعداد کاربران دریافت‌کننده، کل کانفیگ‌های صادرشده و سوابق کامل هر کاربر
- **محدودیت کاربران**: مسدود کردن دریافت کانفیگ، سهمیه اختصاصی و غیرفعال‌کردن هر یک از امکانات ربات به‌صورت جداگانه (منو، دستورها و فایل‌ها)
- **نصب تک‌دستوری** با `install.sh` و **منوی SSH** با `sulduzx`: مدیریت سرویس، تغییر نام کاربری/رمز مدیر، تنظیم دامنه و دریافت خودکار SSL
- ریسپانسیو کامل برای موبایل

## ساختار پروژه

```
.

├── scripts/

├── docker-compose.yml
└── .env.example
```

## پیش‌نیازها

- Docker و Docker Compose
- یک ربات از [@BotFather](https://t.me/BotFather)
- پنل 3x-ui با دسترسی API (نام کاربری/رمز و شناسه اینباند)

## نصب خودکار (تک‌دستوری)

روی یک سرور تازه Ubuntu/Debian (یا هر توزیع با apt/dnf/yum):

```bash
curl -fsSL https://raw.githubusercontent.com/rezafazli1375/sulduzx-bot/main/install.sh | sudo bash
```

نصب‌کننده به‌ترتیب این کارها را انجام می‌دهد:

1. نصب پیش‌نیازها (Docker + Compose، git، curl، openssl) در صورت نبود
2. دریافت پروژه در `/opt/sulduz-bot`
3. پرسیدن توکن ربات، آیدی ادمین، اطلاعات پنل 3x-ui و ساخت نام کاربری/رمز مدیر
4. ساخت `.env` با `JWT_SECRET` و رمز دیتابیس تصادفی (`chmod 600`)
5. `docker compose build` و بالا آوردن سرویس‌ها
6. ساخت جداول دیتابیس (`prisma db push`) و درج داده اولیه (`db:seed`)
7. نصب دستور مدیریت `sulduzx` در `/usr/local/bin`
8. در پایان، آدرس پنل + نام کاربری/رمز مدیر نمایش داده می‌شود

نصب بدون پرسش و با دامنه و SSL خودکار:

```bash
curl -fsSL https://raw.githubusercontent.com/rezafazli1375/sulduzx-bot/main/install.sh | sudo bash -s -- \
  --domain panel.example.com --email you@example.com
```

| گزینه | کار |
| --- | --- |
| `--dir <path>` | مسیر نصب (پیش‌فرض `/opt/sulduz-bot`) |
| `--domain <name>` | دامنه پنل + ساخت Nginx و دریافت گواهی Let's Encrypt |
| `--email <mail>` | ایمیل Let's Encrypt |
| `--no-ssl` | بدون تنظیم دامنه/SSL |
| `--yes` | بدون پرسش (مقادیر از متغیرهای محیطی: `BOT_TOKEN`, `ADMIN_IDS`, …) |
| `--force-env` | بازنویسی `.env` موجود |
| `--dry-run` | نمایش کارها بدون تغییر سیستم |
| `--repo <url>` / `--branch <name>` | مخزن/شاخه جایگزین |

## منوی SSH: `sulduzx`

بعد از نصب، در SSH کافی است بنویسید:

```bash
sulduzx
```

```
  1) وضعیت سرویس‌ها
  2) روشن / ری‌استارت
  3) توقف سرویس‌ها
  4) مشاهده لاگ‌های ربات
  5) تغییر نام کاربری مدیر پنل
  6) تغییر رمز عبور مدیر پنل
  7) تنظیم دامنه و دریافت SSL خودکار
  8) ویرایش فایل .env
  9) بکاپ دستی دیتابیس
  10) به‌روزرسانی و بیلد مجدد
  0) خروج
```

همه گزینه‌ها به‌صورت دستور مستقیم هم قابل اجرا هستند:

```bash
sulduzx status                 # وضعیت کانتینرها + سلامت API
sulduzx username myadmin       # تغییر نام کاربری مدیر
sulduzx password               # تغییر رمز مدیر (بدون نمایش روی صفحه)
sulduzx domain --domain panel.example.com --email you@example.com
sulduzx backup                 # بکاپ gzip در data/backups
sulduzx update                 # دریافت نسخه جدید + بیلد + db push
```

گزینه ۷ (دامنه) این کارها را خودکار انجام می‌دهد: نوشتن کانفیگ Nginx (پروکسی به `127.0.0.1:9090`)، اعتبارسنجی با `nginx -t`، دریافت گواهی Let's Encrypt با `certbot --nginx --redirect`، و به‌روزرسانی `ADMIN_PANEL_URL` در `.env`. با `--staging` می‌توانید اول گواهی آزمایشی بگیرید و با `--print-config` فقط کانفیگ را ببینید.

## نصب دستی

```bash
git clone https://github.com/rezafazli1375/sulduzx-bot.git /opt/sulduz-bot
cd /opt/sulduz-bot

cp .env.example .env
nano .env          # توکن ربات، آیدی ادمین، اطلاعات پنل x-ui و JWT_SECRET را پر کنید

docker compose up -d --build
```

سپس:

```bash
# ساخت جداول دیتابیس
docker compose exec -T bot npx prisma db push

# داده‌های اولیه (ادمین پنل + تنظیمات پیش‌فرض)
docker compose exec -T bot npm run db:seed
```

- پنل مدیریت: `http://SERVER_IP:9090`
- ورود اولیه: `ADMIN_USERNAME` / `ADMIN_PASSWORD` از `.env` (اگر تنظیم نشده باشد: `admin` / `admin123`)
- **بعد از اولین ورود، از صفحه «حساب کاربری» یا با `sulduzx password` رمز را عوض کنید.**

### تنظیمات مهم `.env`

| کلید | توضیح |
| --- | --- |
| `BOT_TOKEN` | توکن ربات از BotFather |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها، با کاما جدا شود |
| `POSTGRES_*` / `DATABASE_URL` | اطلاعات دیتابیس؛ اگر رمز را عوض کردید هر دو را هم‌تراز کنید |
| `PANEL_BASE_URL` | آدرس پنل 3x-ui مثل `https://panel.example.com:8443` |
| `PANEL_USERNAME` / `PANEL_PASSWORD` | اطلاعات ورود پنل |
| `PANEL_INBOUND_ID` | شناسه اینباندی که کانفیگ‌ها روی آن ساخته می‌شوند |
| `JWT_SECRET` | کلید امضای توکن پنل (`openssl rand -hex 32`) |
| `ADMIN_PANEL_URL` | آدرس عمومی پنل برای نمایش در پیام ربات |
| `YTDLP_PROXY` | (اختیاری) پروکسی پیش‌فرض دانلودر مثل `socks5h://1.2.3.4:1080` |

## استفاده

1. وارد پنل شوید (`:9090`).
2. در صفحه **ربات‌ها** ربات را ببینید/اضافه کنید (اگر `BOT_TOKEN` ست شده باشد، ربات اصلی خودکار ساخته می‌شود).
3. در **کانال‌ها** کانال‌های عضویت اجباری را برای هر ربات ثبت کنید (ربات باید ادمین کانال باشد).
4. در **تنظیمات** اطلاعات پنل x-ui، محدودیت کانفیگ رایگان، پروکسی دانلودر و… را تنظیم کنید.
5. متن‌ها و دکمه‌های منو را از صفحه‌های **متن‌های ربات** و **منوی ربات** دلخواه کنید.
6. از صفحه **بکاپ و بازگردانی** نسخه پشتیبان بگیرید (فایل‌ها در `./data/backups` ذخیره می‌شوند).
7. در صفحه **کانفیگ‌ها** آمار دریافت کانفیگ و سوابق هر کاربر را ببینید.
8. در صفحه **کاربران** با دکمه «محدودیت‌ها» دریافت کانفیگ یا هر امکان ربات را برای یک کاربر خاص محدود کنید.

## نکات امنیتی

- فایل `.env` را هرگز commit نکنید (در `.gitignore` هست).
- `JWT_SECRET` و رمز دیتابیس را قوی انتخاب کنید (نصب‌کننده اینها را تصادفی می‌سازد و `.env` را با دسترسی `600` ذخیره می‌کند).
- پورت دیتابیس (`5432`) و API (`3000`) فقط به `127.0.0.1` بایند شده‌اند؛ پنل از پورت `9090` در دسترس است.
- بکاپ‌ها حاوی داده کاربران هستند و در `./data/backups` قرار می‌گیرند (از repo خارج هستند).
- پنل مدیریت را پشت HTTPS بگذارید: `sulduzx` → گزینه ۷ (Nginx + Let's Encrypt خودکار).
- برای تغییر رمز مدیر از `sulduzx password` استفاده کنید؛ رمز از stdin خوانده می‌شود و در تاریخچه shell نمی‌ماند.
- حساب‌های `admin_users` در فایل بکاپ نیستند تا بازگردانی باعث قفل‌شدن دسترسی نشود.

## تغییرات نسخه ۱.۱.۰

- **پروکسی دانلودر با کانفیگ V2Ray**: در صفحه تنظیمات، حالت اتصال دانلودر را روی `V2Ray` بگذارید و لینک `vless://`، `vmess://`، `trojan://`، `ss://` یا یک کانفیگ JSON (outbound یا config کامل xray) را وارد کنید. `xray-core` داخل ایمیج ربات نصب است و یک پروکسی SOCKS محلی می‌سازد؛ نیازی به نصب دستی چیزی روی سرور نیست.
- **تست اتصال**: کنار تنظیمات پروکسی، دکمه «تست اتصال» به API جدید `POST /api/ytdlp/test` وصل است و قبل از ذخیره، تاخیر، IP خروجی و دسترسی به یوتیوب را نشان می‌دهد.
- **مهاجرت خودکار**: اگر قبلاً پروکسی SOCKS را با کلیدهای قدیمی فعال کرده بودید، حالت `socks` به‌طور خودکار از همان تنظیمات قبلی ساخته می‌شود.
- به‌روزرسانی نسخه‌ها به `1.1.0`.
